Borrowing Process
- after the product instance is borrowed, it should go to borrowed product tables ans set the status as borrowed
- if product instance is returned remove from the table and add it to returned product then set the status back to available

- borrowing product is necessary to have a room for tracking
- product details should have history of previous location and borrower and current status if borrowed
